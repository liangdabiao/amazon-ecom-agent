# 知识库目录

把你的亚马逊运营知识文档（markdown 格式）放进这个目录，助手回答
政策、费用、FBA 规则等事实性问题时会自动检索这里，并注明来源文件。

可以按主题建子目录，例如：

```
knowledge/
├── fees/          # 费用：FBA 费用、仓储费、佣金
├── policy/        # 政策：跟卖、review 政策、账户健康
├── listing/       # Listing 规范、标题规则
└── fba/           # 入仓、物流、库存管理
```

> 提示：IvyeaAgent 仓库 `knowledge_base/` 下有成套整理好的亚马逊运营知识，
> 可以直接拷过来用。

此目录内容不进 git（每台机器放自己的），本 README 除外。
